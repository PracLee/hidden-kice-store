# 이미지 에셋 가이드

PNG 파일을 아래 규칙대로 넣어주면 코드 수정 없이(데이터 파일만 갱신) 바로 반영됩니다.

## products/ — 상품 카드 이미지

둘 중 편한 방식으로:

**방식 A. 공통 이미지 2장** (현재 시안 기준 충분)
- `single.png` — 단권 검정 표지 (단품 카드용)
- `set.png` — 5권 컬러 세트 (패스 카드용)

**방식 B. 상품별 개별 이미지** (상품마다 다르면)
- `p01.png` ~ `p12.png` — 상품 id와 동일한 파일명

권장 사이즈: 정사각형 기준 600×600 이상, 배경 투명 또는 흰색

## hero/ — 메인 배너

- `hero-books.png` — 배너 우측 교재 3권 연출 이미지 (배경 투명 권장, 800px 이상)

이미지가 없는 상품은 지금처럼 CSS로 그린 표지(BookCover)가 대신 표시됩니다.
